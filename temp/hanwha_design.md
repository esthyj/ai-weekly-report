# 한화그룹 디자인 시스템 (design.md)

> 한화손해보험 AI리서치센터 산출물(주간 AI 트렌드 리포트, 자동 생성 PPT 등)의
> 브랜드 일관성을 확보하기 위한 디자인 레퍼런스 문서입니다.
> 표기된 정확한 색상/서체 값은 사내 공식 「한화 브랜드 가이드라인」으로 최종 확인하세요.

---

## 1. 브랜드 아이덴티티

### 1.1 CI — 한화 트라이서클 (Hanwha Tri-Circle)
- 끊임없는 변화와 혁신을 통해 무한 진화·팽창·성장하는 **세 개의 원**으로 구성된 심볼마크입니다.
- 세 개의 원은 **고객 · 사회 · 인류**의 조화로운 발전을 상징하며, 동시에 그룹의 **핵심가치 · 비전 · 세 가지 사업 부문**을 의미합니다.
- 원의 배치 순서는 ① 상단 → ② 중앙 → ③ 하단으로 고정되며, 임의로 변경할 수 없습니다.

### 1.2 브랜드 에센스
- **Energy for Life**
- 역동적인 에너지를 통해 무한 성장의 느낌을 전달하는 것을 핵심 정서로 삼습니다.

### 1.3 적용 원칙
- 모든 비주얼은 CI 모티프를 기준으로 표현하는 것을 원칙으로 합니다.
- Identifier(심볼·로고)의 **형태·비례·색상은 변형 금지**이며, 반드시 규정된 디지털 원본 파일을 사용합니다.

## 2. 컬러 시스템

### 2.1 메인 컬러 — Hanwha Orange
한화의 대표 컬러입니다. 인쇄물은 Process Color(CMYK), 디지털은 RGB를 기준으로 적용하며 **백색 배경**을 원칙으로 합니다.

| 항목 | 값 (참고) | 비고 |
|------|-----------|------|
| Pantone | **165 C** | 별색 인쇄 기준 |
| HEX | `#F37321` *(또는 #FF6720 계열)* | ※ 사내 가이드 값으로 확정 필요 |
| RGB | 243, 115, 33 | TV·웹·방송 데이터 |
| CMYK | 0, 65, 95, 0 | 신문·잡지·실사 출력 |

> ⚠️ 공개 자료마다 Hanwha Orange의 HEX 표기가 `#F37321`~`#FF6720`로 다르게 나타납니다.
> PPT/리포트 템플릿에 박아 넣기 전 **공식 가이드라인의 정확한 값**으로 반드시 교차 확인하세요.

### 2.2 서브 / 뉴트럴 컬러
오렌지를 보조하고 본문 가독성을 확보하기 위한 무채색 계열입니다.

| 역할 | 이름 | HEX (제안) |
|------|------|------------|
| 본문 텍스트 | Charcoal | `#222222` |
| 보조 텍스트 | Dark Gray | `#595959` |
| 구분선·캡션 | Mid Gray | `#9E9E9E` |
| 배경·표 음영 | Light Gray | `#F2F2F2` |
| 베이스 | White | `#FFFFFF` |

### 2.3 시맨틱 컬러 (데이터·상태 표현용)
리포트 내 차트·표·강조 표기에 사용합니다.

| 의미 | HEX (제안) |
|------|------------|
| 긍정/성장 | `#2E7D32` |
| 주의/하락 | `#C62828` |
| 정보/링크 | `#1565C0` |
| 강조(브랜드) | Hanwha Orange |

### 2.4 사용 비율 가이드
- **60% 화이트(배경) / 30% 뉴트럴 / 10% Hanwha Orange** 를 기본 비율로 권장합니다.
- 오렌지는 **포인트 컬러**로만 사용하고, 본문 대량 텍스트에는 사용하지 않습니다.

## 3. 타이포그래피

### 3.1 서체 원칙
- 공식 인쇄·브랜딩물은 **한화 전용 서체**(브랜드 가이드 지정)를 우선 사용합니다.
- 디지털·문서 산출물에서 전용 서체 사용이 어려운 경우, 아래 대체 서체를 사용합니다.

### 3.2 권장 대체 서체

| 용도 | 한글 | 영문/숫자 |
|------|------|-----------|
| 제목 | Noto Sans KR Bold / Pretendard Bold | Noto Sans / Arial Bold |
| 본문 | Noto Sans KR Regular / Pretendard | Noto Sans Regular |
| 데이터·표 | Noto Sans KR Medium | 등폭 숫자 권장 |

### 3.3 위계 (Type Scale) — 문서/슬라이드 기준

| 레벨 | 크기(pt) | 굵기 |
|------|----------|------|
| 표지 타이틀 | 32–40 | Bold |
| 섹션 제목 (H1) | 24 | Bold |
| 소제목 (H2) | 18 | SemiBold |
| 본문 | 11–12 | Regular |
| 캡션·각주 | 9 | Regular |

- 줄간격(행간)은 본문 기준 **1.4–1.6배**를 권장합니다.

## 4. 로고 사용 규정

- **여백(Clear Space):** 로고 주변에는 심볼 원 지름의 1/2 이상 여백을 확보합니다.
- **최소 크기:** 가독성이 보장되는 최소 크기 이하로 축소하지 않습니다.
- **금지 사항:**
  - 색상·비례·형태 변형
  - 회전, 그림자·외곽선 등 임의 효과 적용
  - 복잡한 배경·저대비 배경 위 배치
  - 원본이 아닌 캡처·재제작 파일 사용
- **배경별 운용:** 밝은 배경 = 컬러 로고 / 어두운 배경 = 화이트(역상) 로고.

---

## 5. 레이아웃 & 그리드

- **그리드:** 슬라이드는 12컬럼, 문서는 본문 1단 + 사이드 캡션 구조를 기본으로 합니다.
- **여백:** 슬라이드 가장자리 최소 5% 마진 확보.
- **정렬:** 텍스트 좌측 정렬을 기본으로 하며, 표지·간지에서만 중앙 정렬 허용.
- **강조 막대(Bar):** 섹션 제목 좌측에 Hanwha Orange 세로 막대를 두어 브랜드 일관성을 줍니다.

---

## 6. 컴포넌트 (리포트/PPT 공통)

### 6.1 표지
- 상단/하단 코너에 로고, 중앙에 타이틀, 하단에 작성 부서·일자.
- 배경은 화이트 또는 라이트 그레이, 포인트로 오렌지 막대 1개.

### 6.2 표(Table)
- 헤더 행: 라이트 그레이 배경 + Bold.
- 본문 행: 화이트 / 라이트 그레이 교차(zebra).
- 강조 셀: Hanwha Orange 텍스트 또는 옅은 오렌지 배경(`#FDE7D8` 제안).

### 6.3 차트
- 단일 시리즈: Hanwha Orange.
- 다중 시리즈: 오렌지 → 차콜 → 미드 그레이 → 시맨틱 블루 순.
- 격자선은 라이트 그레이, 데이터 라벨은 차콜.

### 6.4 인용·인사이트 박스
- 좌측 오렌지 막대 + 라이트 그레이 배경으로 핵심 인사이트를 분리 표기.

## 7. OrangePick 산출물 적용 가이드

자동 생성 파이프라인(뉴스 수집 → 요약 → 인사이트 → PPT)에서 본 디자인 시스템을 다음과 같이 연결합니다.

- **템플릿화:** 표지·간지·본문·차트 슬라이드를 마스터 슬라이드로 사전 정의하고 색/서체 토큰을 본 문서 값으로 고정.
- **색상 토큰:** `--hanwha-orange`, `--charcoal`, `--light-gray` 등 변수로 관리해 한 곳에서 변경 가능하도록 구성.
- **휴먼 검수 단계:** 최종 인사이트 선별 시 브랜드 톤(절제된 오렌지 사용, 좌측 정렬, 백색 배경) 준수 여부를 체크리스트로 점검.
- **출력 포맷:** 인쇄 배포용은 CMYK, 화면 공유용은 RGB 자산을 분리 관리.
